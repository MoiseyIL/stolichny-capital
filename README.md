# Столичный капитал

Экономическая настольная игра с улицами Москвы в стиле начала 90-х: покупайте улицы, стройте дома и отели, разоряйте соперников. Вы играете против компьютерных соперников, за столом от 2 до 6 игроков.

Игра — это веб-приложение (PWA): её можно установить на телефон или компьютер, она работает без интернета и сохраняет партию.

## Как включить сайт

1. Откройте в репозитории **Settings → Pages**.
2. В разделе **Build and deployment** выберите **Source: Deploy from a branch**.
3. Ветка **main**, папка **/ (root)**, нажмите **Save**.
4. Через минуту-две игра будет доступна по адресу `https://<ваш-логин>.github.io/stolichny-capital/`.

## Как установить на телефон

- **Android (Chrome):** откройте сайт и нажмите «Установить на телефон» на стартовом экране игры или в меню браузера пункт «Установить приложение».
- **iPhone (Safari):** кнопка «Поделиться», затем «На экран «Домой»».
- **Компьютер (Chrome, Edge):** значок установки в адресной строке.

## Android-приложение (APK)

Каждый push в `main` собирает APK через GitHub Actions и выкладывает его в **Releases**.

1. На телефоне откройте https://github.com/MoiseyIL/stolichny-capital/releases/latest
2. Скачайте файл `stolichny-capital-1.0.N.apk` из раздела Assets.
3. Откройте скачанный файл. Android попросит разрешить установку из браузера или «Файлов»: разрешите.
4. Обновления ставятся поверх старой версии, сохранённая партия остаётся.

Собрать заново вручную: вкладка **Actions** → **Android APK** → **Run workflow**.

APK подписан ключом из `android-keystore/` (пароль в `.github/workflows/android.yml`). Для установки с файла этого достаточно. Для Google Play создайте отдельный ключ загрузки и храните его в секретах репозитория, а не в коде.

Как это устроено: `scripts/prepare-www.mjs` собирает папку `www` и кладёт шрифты внутрь, Capacitor заворачивает её в Android-приложение, `@capacitor/assets` делает иконки и заставку из папки `assets/`.

## Файлы

- `index.html` — вся игра.
- `manifest.webmanifest` — название, цвета и иконки приложения.
- `sw.js` — офлайн-кэш. После изменения файлов увеличьте `VERSION`, чтобы у игроков подтянулось обновление.
- `icons/` — иконки сайта.
- `assets/` — исходники иконки и заставки Android-приложения.
- `capacitor.config.json`, `package.json`, `scripts/`, `.github/workflows/android.yml` — сборка APK.

Сохранение партии хранится в браузере на устройстве игрока.

Игра не связана с Hasbro и торговой маркой «Монополия».
